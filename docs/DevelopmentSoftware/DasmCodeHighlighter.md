# D-ASM Syntax Highlight
D-Asm is the name of the assembly language used to program the CPU with.

Files may use the `.dasm` or `.asm` file extention to be detected by the highlighter.

As of now, it is very limited and has no autocompletion or syntax helper.
It's purely a syntax highlight extension.

## Installation
Open the extensions folder of Visual Studio Code. <br>
Common path is: <br>
`C:\Users\<YOUR_USER>\.vscode\extensions`

Once you localized the extensions folder:<br>
1. Copy the `local.dasm` folder
2. Paste it into the extensions folder
3. Reload Visual Studio Code
